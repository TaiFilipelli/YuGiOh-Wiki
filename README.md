# YugiohWiki

This project was entirely developed with [Angular CLI](https://github.com/angular/angular-cli) version 18.2.0. 

## Descripción

This project has no other goal than showing my skills in Angular, a popular framework that i learned last year. Angular is a beautiful framework that can allow you to create websites with a lot of interactivity, and altought it has it's issues, it is still one of the best frameworks for web development.

The app allows the users to visualize YuGiOh cards thanks to a huge library with more than 13.000 cards. Each card has its own statistics and description, as it also allows to see the values of each card in diferent stores.

The app uses absolutely all the tools that Angular has to offer: pipes/operators, HTTP requests to an [external API](https://ygoprodeck.com/api-guide/), services, components, inputs, observers, subjects, some good practices in the design of watchers, etc. All details related to the code can be easily looked in this repository.
